# 单一 Piano 与完整历史导航

本次从已合入 PR #1 的 `4eb664d` 新建实现，不修改已合入 PR。

## 用户可见行为

只显示一个 Piano 导航。未加载历史也有轮次入口，显示已有 prompt/response 大纲；点击后加载并跳转。已加载轮次展开为真正的用户消息与可见助手输出段。`maxVisible` 只是可见窗口大小，不是历史上限；滚轮、Home/End、PageUp/PageDown 和上下键可遍历全部入口。

Piano 关闭、容器过窄或适配契约不满足时，恢复官方导航，不并排保留两条导航。恢复的是官方行为，因此其自身的窄容器隐藏规则仍然适用。

## 不复制 ChatView 的实现方式

DSH 0.1.5-rc.2 尚无独立 navigator slot。为使现有安装直接可用，本版采用**经过完整按钮映射校验的 DOM 桥接**，而不是声称存在官方替换 API：

- `session.projections.faceOf('turnOutline')` + Chat target 的 `navigation.items()` 提供完整轮次读模型。
- 已加载的可见段来自 PR #1 的 keyed Chat source。
- 官方 `TurnNavigator` 和 `ChatView` 保持挂载。Piano 的轮次点击转发到真实官方按钮；未加载历史的 `loadThrough`、分页锚点、落点、底部跟随及阅读恢复均由原 ChatView 执行。
- 接管成功后，仅对该视图的官方 nav 设置 `display:none!important` 和 `aria-hidden`；禁用/卸载/契约失配逐项恢复原值。不读取 React Fiber、不覆写函数、不修改 DSH 安装文件、不加载其他会话。
- 细粒度已加载段先通过官方轮次动作取消旧跳转，再定位该行，交由官方 scroll/scrollend 监听保存最终阅读位置。
- Escape、正文滚轮/触摸/阅读键通过官方的已加载轮次动作撤销待落地跳转，然后保持阅读位置。**这是取消跳转意图，不是中止官方共享的网络分页请求。** 已发请求可以完成，但不得再把阅读位置拉回旧目标。

桥接不是永久稳定公共 API。它按官方本地化 aria 标签精确匹配完整、无歧义的轮次按钮集合；结构或标签不符立即恢复官方界面。今后有正式 navigator port 时，只替换 `native-navigation.ts`，不改琴键读模型。

## 稳定性和数据边界

未加载轮次只显示一个 `turn:N` 入口，不根据预览猜测段数。加载后第一个真实段继承该键，其他段保留节点身份；全量大纲按整值替换，不能累计旧大纲。隐藏正文不会泄漏到预览。工具、推理、内部状态不生成琴键。插件不持久化第二份会话，也不自行循环调用 `loadOlder/loadThrough`。

## 验证

- 纯逻辑：大纲与加载窗口合并、非法条目、重复替换、占位转真实段、稳定 key。
- jsdom：单一可见导航、全部历史可达、滚轮/键盘、加载状态、重试、取消、原地流式、契约失配和完整卸载。
- Chromium：使用固定 DSH 源码的原始 `ChatView`、`TurnNavigator` 和合并逻辑；仅消息叶子组件与 Session 数据传输是测试替身。验证原始分页/滚动恢复代码，不把 jsdom 模拟导航当成真实 ChatView。
